## Findings classified

### Must-fix (blocks merge)

_None._

### Recommended (apply during implementation)

1. **Copy button shows "Copied!" then reverts.** 1.5s timer, swap textContent in place. Don't use a tooltip — it's flaky on touch.
2. **Dismiss button text "Got it"** (issue body) — short, decisive. Stack below the Copy button (or to its right) inside the panel footer.
3. **Empty-state link external?** API docs are at `docs.subnetcalculator.app` (separate hostname). Add `target="_blank" rel="noopener"` to opens-in-new-tab semantics — operator's mid-flow workspace stays.
4. **Panel keeps `role="alert"`.** Existing markup already has it; preserve so screen readers announce the new key.

### Nice-to-have (deferred)

1. **SHA-256 fingerprint** alongside the token for operators who want to verify integrity later. Out of scope.
2. **QR code of the token** for mobile-only operators. Same QR rabbit hole as Task 6 — out of scope.
3. **Toast notification** instead of inline "Copied!" — project hasn't standardised on a toast pattern yet.
