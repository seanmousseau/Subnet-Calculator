## TL;DR for handover

v3.3.0 is the **first** of four IPv6-themed minor releases. It ships five new
tools — `range6`, `supernet6`, `zone-id`, `derive`, `slaac-privacy` — as
**drawer entries on the existing IPv6 tab**. **No new top-level tabs.** No
new design tokens. GMP throughout for IPv6 arithmetic.

Sequencing intent: parity ports first (range6, supernet6 mirror their v4
siblings), then the IPv6-native tools (zone-id, derive, slaac-privacy). The
plan locks each tool to its own PR off `release/v3.3.0`; only the release-cut
PR (PR7) merges `release/v3.3.0` into `main`.

**No deferrals without explicit user approval.** Every Acceptance checkbox in
each issue must have a corresponding code change AND a test before its PR
opens.

## Cross-cutting design decisions (locked)

1. **Drawer-only UI.** All five tools land as `data-tool="..."` drawer entries
   on the existing IPv6 tab — mirror existing markup in `templates/layout.php`.
2. **No new top-level tabs.**
3. **No new design tokens.** Consume existing `--color-*` only; teal accent
   `#06d6a0` and dark text on teal buttons (per v2.9.0 style guide).
4. **GMP throughout** for IPv6 arithmetic — never PHP signed int math on
   addresses or counts. Counts that overflow signed 64-bit print as the
   `"2^N"` string form already used by `calculate_subnet6()` and v2.11
   IPv6 VLSM.
5. **RFC vectors in tests.** `Derive6Test` uses RFC 4291 §2.5.1 EUI-64
   vectors (verify U/L bit flips from 0 to 1). `SlaacPrivacyTest` uses
   RFC 8981 §3.3 invariants — bit 6 of byte 8 must be cleared (`0x02`
   mask in PHP byte indexing).
6. **Shareable URL via `sc_run_*` helpers.** Each tool gets one
   `sc_run_<tool>` helper in `Subnet-Calculator/includes/request.php` that
   handles both POST submission and GET hydration, populating the same
   template globals regardless of method. Same pattern as v2.11
   `sc_run_lookup` / `sc_run_diff`.
7. **`help_bubble()` on every input.** Inherited a11y (tabindex/role/aria
   from v2.5.0) means no extra wiring per bubble.
8. **No new design tokens, no new tabs.** Restated for emphasis — these are
   the two most-likely-to-erode invariants of the milestone.
