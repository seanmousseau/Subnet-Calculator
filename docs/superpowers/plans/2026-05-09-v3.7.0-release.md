## Task 7: A11y polish

**Branch:** `feature/v3.7.0-a11y-polish` off `release/v3.7.0`.

**Files:**
- Modify: `testing/scripts/playwright_test.py` — strengthen tab-order, prefers-reduced-motion, focus-return tests.

### Improvements

**Tab-order strictness:** v3.6.0 T6 tests asserted Tab from outside drawer
focuses *inside* the drawer (containment). Add a stricter test: Tab
visits the drawer's inputs in DOM order, then submit, then result-area
copy buttons. Per drawer.

**`prefers-reduced-motion` explicit per drawer:** v3.6.0 T6 tested one
drawer (`nibble`). Add tests for ALL drawers (≥30) confirming
`transition-duration` is ≤ 10ms when `reduced_motion: reduce` emulated.

**Focus-return per drawer:** v3.6.0 T6 covered the 9 v3.5.0 drawers and
4 v3.6.0 drawers. Confirm all drawers (≥30) restore focus to the
originating trigger button after ESC.

### Process

- [ ] **Step 1: Iterate tests for each drawer.** Use a test data structure
  listing every `data-tool` slug to drive the assertions; one Playwright
  test method per concern, parameterized over the slug list.
- [ ] **Step 2: Run `make test-docker`** — full Playwright suite passes.
- [ ] **Step 3: Run all 7 QA gates.**
- [ ] **Step 4: Commit, push, PR.**

### Acceptance

- Every drawer has explicit tab-order, prefers-reduced-motion, and
  focus-return assertions.
- Playwright assertion count grows by ~90 (3 assertions × 30 drawers).
- All 7 gates green.
