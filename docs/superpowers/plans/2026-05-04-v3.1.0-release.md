> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Mandatory consultations:**
> - **`ui-ux-pro-max` skill** — invoke before AND after any markup/CSS edit on a UI-bearing task (#321, #322, #323, #327, #328) to ensure visual + interaction parity with the v2.9.0 style guide and the existing tool-drawer language.

>

**Goal:** Ship v3.1.0 covering all 8 milestone-23 issues (#321–#328) — IPv6 drawer parity, multi-tree diff, tree presets, test-rig hygiene, audit purge strategy, PHPCS admin scope, history capture parity, keyboard tab-focus ergonomics — with a unified design language and complete docs.

**Architecture:** Sequential PR fan-out off `release/v3.1.0`, modelled on v3.0.0's PR1–PR4 pattern. Each issue is its own PR; all PRs merge into `release/v3.1.0`; the final release-cut PR opens `release/v3.1.0 → main`. Test-rig hygiene (#324) ships first so the rest of the work can rely on deterministic admin state. Server-side hardening (#325, #326) ships next; UI alignment (#321) follows; large features (#322, #323) come after the foundation; UX polish (#327, #328) closes out before the release cut.

**Tech Stack:** PHP 8.2+ (strict types, GMP), SQLite3, plain JS + BigInt, mkdocs + spectral, PHPUnit 11, Playwright 1.4x via docker, PHPStan L9, PHPCS PSR-12, Semgrep.

function audit_log(\SQLite3 $db, string $action, ?string $actor, ?string $ip, ?int $key_id, array $meta): void
{
    // ...existing insert...

    global $admin_audit_purge_strategy, $admin_audit_purge_sample_rate;
    $strategy = $admin_audit_purge_strategy ?? 'sampled';
    $sample = (float)($admin_audit_purge_sample_rate ?? 0.001); // 0.1% default

    switch ($strategy) {
        case 'inline':
            audit_purge($db);
            break;
        case 'sampled':
            if (mt_rand() / mt_getrandmax() < $sample) {
                audit_purge($db);
            }
            break;
        case 'cron':
        default:
            // No-op — operator runs bin/sc-audit-purge.php on a schedule.
            break;
    }
}
