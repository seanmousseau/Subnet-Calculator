## Cross-cutting design decisions (locked)

1. Admin pages render exactly one outer `.card` — sub-sections are dividers, not nested cards.
2. Cookie session uses `admin_sessions` table; cookie attributes `HttpOnly; Secure; SameSite=Lax`; CSRF token bound to the session row.
3. `config-admin.php` is the wizard-tier file; `config.php` operator hand-edits always win and the Settings page surfaces a "shadowed by config.php" banner.
4. `audit_action_badge_class($action): string` lives in `functions-audit.php` so #346 + #348 + #349 share one mapping.
5. Test rig drain (#324 from v3.1.0) is extended whenever a new admin DB table or k/v store is introduced (`admin_sessions`, `admin_state`).
6. Schema migrations are additive (`ALTER TABLE … ADD COLUMN`) — no data loss on upgrade.
