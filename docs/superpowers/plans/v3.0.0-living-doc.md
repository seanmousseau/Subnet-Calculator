## Cross-cutting design decisions (locked)

1. **Session schema is bumped once** in PR1 (#315) to a versioned v2 with a
   `type` discriminator. `'ipv4' | 'ipv6'` ship in PR1, `'tree'` is added by
   PR3 (#302). The schema file allows all three from PR1 to avoid a second
   bump mid-release — server validation for `'tree'` activates in PR3 but the
   schema is already permissive.
2. **Admin config file is split.** `config-admin.php` is the wizard target and
   may be auto-written. `config.php` remains hand-edited only. PR2 introduces
   the split; PR1 should already include `config-admin.php` to the
   `require_once` chain in `index.php` so the wizard has somewhere to write.
3. **Audit log is the cross-feature breadcrumb.** First-run wizard, TOTP, key
   mint/revoke all write into the same `admin_audit` table from PR1. PR2
   features just call `admin_audit_log($action, $meta)`.
4. **No new runtime dependencies.** TOTP is hand-rolled. Tree editor is plain
   JS (no React/Vue). Keep the `vendor/xlsx/` SRI pattern as the only
   third-party JS.
5. **Mobile-aware but desktop-first** for new UI. Tree editor explicitly
   degrades to action sheets on touch (per design lock §"Mobile interaction
   model"). Keyboard overlay is desktop-only (touch users can't trigger `?`).

## QA gates (run before every PR)

```bash
# PHP syntax + static analysis
php -l Subnet-Calculator/index.php
phpstan analyse --no-progress --memory-limit=512M

# PHPCS PSR-12
vendor/bin/phpcs --standard=PSR12 Subnet-Calculator/includes/ Subnet-Calculator/api/

# Unit tests
vendor/bin/phpunit

# OpenAPI lint
npx --yes @stoplight/spectral-cli@6 lint Subnet-Calculator/api/openapi.yaml

# Security
semgrep --config=.semgrep/rules.yml --config p/php --config p/owasp-top-ten \
        --config p/sql-injection --error \
        Subnet-Calculator/includes/ Subnet-Calculator/api/ Subnet-Calculator/templates/

# JS / CSS lint
npm run lint

# Full Playwright suite (no dev server needed)
make test-docker
```

All must be green before opening / pushing to a PR.

## Pointers for the next agent

- **Read the project `CLAUDE.md`** at repo root — it has the full file layout
  and the long list of "do not break this" invariants (CSS tokens, GMP usage,
  CIDR auto-detection, etc.).
- **Memory MCP** is wired up — load `user:sean` and `project:simple-php-ipam`
  entities at start of every session.
- **Local git remote is a session-scoped proxy.** `git push` may not actually
  reach GitHub — verify via `gh api` or `mcp__github__list_commits`.
- **Don't touch `--color-bg` or `--color-btn-text` CSS tokens** — they break
  iframe consumers and WCAG contrast respectively.
- **Tests live in `testing/unit/` (PHPUnit) and `testing/scripts/playwright_test.py`.**
  Add tests **alongside the code change in the same PR**, not as a follow-up.
