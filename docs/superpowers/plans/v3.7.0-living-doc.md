## Cross-cutting design decisions (locked)

1. **No behaviour change in T2.** Markup output must be byte-for-byte identical to v3.6.4 modulo include whitespace. Playwright suite is the safety net.
2. **All tool groups default-open on first visit (T3).** Persist user-collapse state in `localStorage`. No surprise hiding.
3. **Anchored rsync excludes (T8).** `--exclude='/config.php' --exclude='/data/'` per v3.5.0 deploy-runbook fix.
4. **`sleep 3` after `systemctl restart lsws` (T8).** Per v3.6.3 deploy lesson — OPcache settle time.
5. **`ui-ux-pro-max` consult before AND after every markup/CSS edit** (T2, T3, T4, T7).
6. **No new design tokens, no new top-level tabs, no new API endpoints.**
