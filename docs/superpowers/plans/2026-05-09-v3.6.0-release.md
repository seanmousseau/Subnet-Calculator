### Function signatures

```php
declare(strict_types=1);

/**
 * Decode an IPv6 multicast address per RFC 4291 §2.7.
 *
 * Returns:
 *   [
 *     'address'      => string,        // canonical compressed form
 *     'scope'        => int,           // 1..15 (only certain values are well-defined)
 *     'scope_name'   => string,        // 'interface-local' | 'link-local' | 'admin-local' | etc. | 'reserved'
 *     'flags'        => int,           // 4 bits: 0RPT
 *     'transient'    => bool,          // T flag
 *     'prefix_based' => bool,          // P flag (RFC 3306)
 *     'embedded_rp'  => bool,          // R flag (RFC 3956)
 *     'group_id'     => string,        // 112-bit group ID as hex string (28 chars)
 *     'scheme'       => string,        // 'well-known'|'transient'|'ssm'|'embedded-rp'|'reserved'
 *     'detail_route' => string|null,   // '/ipv6/ssm' or '/ipv6/embedded-rp' when applicable, else null
 *     'well_known'   => array|null,    // {name, rfc} when matched against the registry; null otherwise
 *   ]
 *
 * Throws InvalidArgumentException if the address is not in FF00::/8.
 */
function decode_multicast(string $ipv6): array;

/**
 * Built-in registry of well-known multicast group addresses.
 *
 * @return array<string, array{name: string, rfc: string}>  keyed by canonical-form address
 */
function multicast_well_known_registry(): array;
```

### Test vectors

```php
public function test_all_nodes_link_local(): void
{
    $r = decode_multicast('FF02::1');
    $this->assertSame(2, $r['scope']);
    $this->assertSame('link-local', $r['scope_name']);
    $this->assertSame(0, $r['flags']);
    $this->assertFalse($r['transient']);
    $this->assertSame('well-known', $r['scheme']);

{
    $r = decode_multicast('FF02::1:FF12:3456');

    $this->assertSame('Solicited-Node Address (RFC 4291)', $r['well_known']['name']);
}

public function test_ssm_group(): void
{
    // FF3E::1234:5678 → scope global, P-flag set, scheme=ssm
    $r = decode_multicast('FF3E::1234:5678');
    $this->assertSame(0xE, $r['scope']);
    $this->assertSame('global', $r['scope_name']);
    $this->assertSame(0x3, $r['flags']);   // P=1, T=1

    $this->assertTrue($r['transient']);
    $this->assertFalse($r['embedded_rp']);
    $this->assertSame('ssm', $r['scheme']);
    $this->assertSame('/ipv6/ssm', $r['detail_route']);
}

    $this->assertSame(0xE, $r['scope']);
    $this->assertSame(0x7, $r['flags']);
    $this->assertTrue($r['embedded_rp']);
    $this->assertSame('embedded-rp', $r['scheme']);

}
```

### Implementation outline

- Validate via `inet_pton`; first byte must be `0xFF`.
- Extract scope from low nibble of byte 0 (`ord($bin[0]) & 0x0F`).
- Extract flags from high nibble of byte 1 (`(ord($bin[1]) & 0xF0) >> 4`).
- Map scope via lookup: `1=interface-local, 2=link-local, 4=admin-local, 5=site-local, 8=organization-local, 0xE=global; others=reserved` (per RFC 4291 §2.7 + RFC 7346).
- Group ID = `bin2hex(substr($bin, 2, 14))` — 14 bytes = 112 bits.
- Scheme decision:
  - `flags & 0x4` (R) set → `embedded-rp`, deep-link `/ipv6/embedded-rp`.
  - `flags & 0x2` (P) set → `ssm`, deep-link `/ipv6/ssm`.
  - `flags & 0x1` (T) set → `transient`.
  - flags == 0 → `well-known` (look up in registry).
  - else → `reserved`.
- Well-known registry: small table seeded from RFC 4291 §2.7.1, RFC 4727, RFC 4291 (solicited-node `FF02::1:FF**:****`), etc. Match exact addresses; for solicited-node, match prefix `FF02::1:FF` (104-bit prefix).

## Task 3: SSM / unicast-prefix-based multicast (RFC 3306) — issue #398

**Branch:** `feature/v3.6.0-ssm` off `release/v3.6.0`.

**Files:** template defaults; module `functions-ssm6.php`; handler `ssm6.php`; drawer `data-tool="ssm"`; endpoint `POST /api/v1/ssm6`; doc `docs/ssm6.md`.

### Function signatures

```php
declare(strict_types=1);

/**
 * Build a unicast-prefix-based / SSM multicast group per RFC 3306.
 *
 * @param string $unicast_prefix  Source unicast prefix (e.g. '2001:db8::/32'), prefix length 0..64.
 * @param int    $scope           1..15 (typically 0xE for global).
 * @param int    $group_id        32-bit group ID (low 32 bits of resulting address).
 *
 * @return array{
 *   address: string,                  // FF3s:00LL:PPPP:PPPP:PPPP:PPPP:GGGG:GGGG (canonical compressed)
 *   scope: int,
 *   prefix_length: int,
 *   unicast_prefix: string,           // canonical (host bits zeroed)
 *   group_id: int,
 * }
 *
 * Throws InvalidArgumentException on invalid prefix, scope, or group_id.
 */
function build_ssm_group(string $unicast_prefix, int $scope, int $group_id): array;

/**
 * Decode an SSM / unicast-prefix-based multicast group.
 *
 * Reverses build_ssm_group; returns the same shape.
 * Throws InvalidArgumentException if the address is not in FF30::/12 (P-flag not set).
 */
function decode_ssm_group(string $ipv6): array;
```

### Test vectors

```php
public function test_build_ssm_global(): void
{
    // RFC 3306 §6 example: 2001:db8::/32, scope 0xE, group 0x12345678
    $r = build_ssm_group('2001:db8::/32', 0xE, 0x12345678);
    $this->assertSame('ff3e:20:2001:db8::1234:5678', strtolower($r['address']));
    $this->assertSame(32, $r['prefix_length']);
}

public function test_build_ssm_short_form_zero_prefix_length(): void
{
    // SSM short form: prefix length 0 means no embedded prefix
    $r = build_ssm_group('::/0', 0xE, 0x12345678);
    $this->assertSame('ff3e::1234:5678', strtolower($r['address']));
    $this->assertSame(0, $r['prefix_length']);
}

public function test_decode_ssm_round_trip(): void
{
    $r = decode_ssm_group('ff3e:20:2001:db8::1234:5678');
    $this->assertSame(0xE, $r['scope']);
    $this->assertSame(32, $r['prefix_length']);
    $this->assertSame('2001:db8::', $r['unicast_prefix']);
    $this->assertSame(0x12345678, $r['group_id']);
}

public function test_build_rejects_prefix_length_over_64(): void
{
    $this->expectException(InvalidArgumentException::class);
    build_ssm_group('2001:db8::1:0:0:0/96', 0xE, 1);  // /96 > /64 ceiling
}

public function test_decode_rejects_p_flag_unset(): void
{
    $this->expectException(InvalidArgumentException::class);
    decode_ssm_group('FF02::1');  // flags=0, not SSM
}

public function test_decode_rejects_non_multicast(): void
{
    $this->expectException(InvalidArgumentException::class);
    decode_ssm_group('2001:db8::1');
}
```

### Implementation outline

- `build_ssm_group`:
  1. Parse prefix → `unicast_prefix_addr_bin` (16 bytes), `prefix_length` (0..64).
  2. Validate scope 1..15, group_id fits in 32 bits, prefix_length 0..64.
  3. Mask host bits of unicast prefix.
  4. Construct 16 bytes: `FF | (3<<4)|scope | (00 LL) | <prefix bytes> | <zeros to fill> | <group_id big-endian>`.
  5. Where: byte 0 = `0xFF`; byte 1 = `(0x3 << 4) | scope` (P+T flags = 3); byte 2 = `0x00`; byte 3 = `prefix_length`; bytes 4–11 = first 8 bytes of unicast prefix (zero-padded); bytes 12–15 = 32-bit group_id.
  6. `inet_ntop()` → canonical address string.
- `decode_ssm_group`: inverse. Validate first byte `0xFF`, second byte high nibble `0x3` (P+T flags). Extract scope, prefix_length, prefix bytes, group_id.

## Task 4: Embedded-RP multicast (RFC 3956) — issue #397

**Branch:** `feature/v3.6.0-embedded-rp` off `release/v3.6.0`.

**Files:** template defaults; module `functions-embedded-rp6.php`; handler `embedded-rp6.php`; drawer `data-tool="embedded-rp"`; endpoint `POST /api/v1/embedded-rp6`; doc `docs/embedded-rp6.md`.

### Function signatures

```php
declare(strict_types=1);

/**
 * Build an embedded-RP multicast group per RFC 3956.
 *
 * @param string $rp_address      RP IPv6 address (e.g. '2001:db8:cafe::1').
 * @param int    $rp_prefix_length  0..64.
 * @param int    $riid             4-bit RP interface ID (0..15).
 * @param int    $scope            1..15.
 * @param int    $group_id         32-bit group ID.
 *
 * @return array{
 *   address: string,            // FF7s:0RIID:RPPP:RPPP:RPPP:RPPP:GGGG:GGGG
 *   scope: int,
 *   rp_prefix: string,
 *   rp_prefix_length: int,
 *   rp_address: string,         // RP-prefix + ::RIID
 *   riid: int,
 *   group_id: int,
 * }
 */
function build_embedded_rp_group(
    string $rp_address,
    int $rp_prefix_length,
    int $riid,
    int $scope,
    int $group_id
): array;

/**
 * Decode an embedded-RP multicast group.
 *
 * Reverses build_embedded_rp_group; returns the same shape.
 */
function decode_embedded_rp_group(string $ipv6): array;
```

### Test vectors

    $this->assertSame(0xE, $r['scope']);
    $this->assertSame(48, $r['rp_prefix_length']);
    $this->assertSame('2001:db8:cafe::', strtolower($r['rp_prefix']));
    $this->assertSame(1, $r['riid']);
    $this->assertSame('2001:db8:cafe::1', strtolower($r['rp_address']));
    $this->assertSame(0x12345678, $r['group_id']);

public function test_build_rejects_riid_over_15(): void

    $this->expectException(InvalidArgumentException::class);
    build_embedded_rp_group('2001:db8::1', 48, 16, 0xE, 1);

### Implementation outline

- `build_embedded_rp_group`:
  1. Parse RP address; validate RIID 0..15, scope 1..15, prefix_length 0..64, group_id < 2^32.
  2. Compute RP prefix (host bits of RP address zeroed).
  3. Construct 16 bytes: byte 0 = `0xFF`; byte 1 = `(0x7 << 4) | scope` (R+P+T flags = 7); byte 2 = `(0x0 << 4) | riid`; byte 3 = `prefix_length`; bytes 4–11 = first 8 bytes of RP prefix; bytes 12–15 = group_id big-endian.
- `decode_embedded_rp_group`: inverse. Validate flags == 7 (R+P+T). Extract RP prefix from bytes 4–11, build RP address by appending `::RIID` to RP prefix.

## Task 5: IPv6 PMTU helper — issue #399

**Branch:** `feature/v3.6.0-pmtu` off `release/v3.6.0`.

**Files:** template defaults; module `functions-pmtu6.php`; handler `pmtu6.php`; drawer `data-tool="pmtu"`; endpoint `POST /api/v1/pmtu6`; doc `docs/pmtu6.md`.

### Function signature

```php
declare(strict_types=1);

/**
 * Compute IPv6 PMTU + fragmentation breakdown.
 *
 * @param int   $path_mtu      Path MTU in bytes (must be >= 1280 per RFC 8200; lower flagged).
 * @param int   $payload_size  Payload size in bytes (0..65535 typical).
 * @param array $extension_headers  List of extension-header byte sizes (each must be multiple of 8 per RFC 8200).
 *                                  Common: HBH=8, routing=8, fragment=8, dest-opts=8.
 *
 * @return array{
 *   path_mtu: int,
 *   meets_minimum: bool,                // path_mtu >= 1280
 *   fixed_header: int,                  // always 40
 *   extension_overhead: int,            // sum of extension_headers
 *   total_overhead: int,                // 40 + extension_overhead
 *   effective_payload: int,             // path_mtu - total_overhead
 *   payload_size: int,
 *   needs_fragmentation: bool,
 *   fragment_count: int,
 *   fragments: list<array{offset: int, m_bit: int, payload_bytes: int}>,
 *   notes: list<string>,                // operator-facing notes (e.g. "PMTU below 1280 minimum")
 * }
 */
function pmtu_compute(int $path_mtu, int $payload_size, array $extension_headers = []): array;
```

### Test vectors

```php
public function test_no_fragmentation_when_payload_fits(): void
{
    $r = pmtu_compute(1500, 1000);
    $this->assertSame(40, $r['fixed_header']);
    $this->assertSame(0, $r['extension_overhead']);
    $this->assertSame(1460, $r['effective_payload']);
    $this->assertFalse($r['needs_fragmentation']);
    $this->assertSame(1, $r['fragment_count']);
    $this->assertTrue($r['meets_minimum']);
}

public function test_fragmentation_when_payload_exceeds(): void
{
    // PMTU 1280, payload 3000; effective payload per fragment = 1280 - 40 - 8 (frag header) = 1232
    // But fragment offsets are multiples of 8, so per-fragment payload is rounded down to 1232.
    // 3000 / 1232 → 3 fragments (1232 + 1232 + 536 = 3000).
    $r = pmtu_compute(1280, 3000, [8]);
    $this->assertTrue($r['needs_fragmentation']);
    $this->assertSame(3, $r['fragment_count']);
    $this->assertCount(3, $r['fragments']);
    $this->assertSame(0, $r['fragments'][0]['offset']);
    $this->assertSame(1, $r['fragments'][0]['m_bit']);
    $this->assertSame(0, $r['fragments'][2]['m_bit']);  // last fragment M=0
}

public function test_below_minimum_flagged(): void
{
    $r = pmtu_compute(1200, 100);
    $this->assertFalse($r['meets_minimum']);
    $this->assertContains('PMTU 1200 is below the IPv6 minimum link MTU (1280) per RFC 8200 §5.', $r['notes']);
}

public function test_extension_headers_accumulated(): void
{
    // HBH (8) + routing (8) + dest-opts (8) = 24 bytes overhead beyond fixed 40
    $r = pmtu_compute(1500, 100, [8, 8, 8]);
    $this->assertSame(24, $r['extension_overhead']);
    $this->assertSame(64, $r['total_overhead']);
    $this->assertSame(1436, $r['effective_payload']);
}

public function test_invalid_path_mtu_rejected(): void
{
    $this->expectException(InvalidArgumentException::class);
    pmtu_compute(0, 100);
}

public function test_extension_header_not_multiple_of_8_rejected(): void
{
    $this->expectException(InvalidArgumentException::class);
    pmtu_compute(1500, 100, [7]);
}
```

### Implementation outline

- `pmtu_compute`:
  1. Validate `path_mtu > 0`, `payload_size >= 0`, each extension header bytes > 0 and multiple of 8.
  2. `meets_minimum = path_mtu >= 1280`.
  3. `total_overhead = 40 + sum(extension_headers)`. If fragmentation is needed, add 8 bytes for the fragment header itself.
  4. `effective_payload = path_mtu - total_overhead` (without fragment header).
  5. If `payload_size <= effective_payload`: no fragmentation; one virtual "fragment" with offset=0, m_bit=0.
  6. Else: each fragment carries `floor((path_mtu - total_overhead - 8) / 8) * 8` bytes (rounded to 8-byte boundary). Last fragment carries the remainder (may be smaller). Fragment offsets are multiples of 8: `0, 8, 16, ...` representing 8-byte units. M=1 for all but the last.
  7. Notes: surface `< 1280` warning, fragmentation note ("End-host fragmentation only; routers do not fragment IPv6 per RFC 8200 §5.").
