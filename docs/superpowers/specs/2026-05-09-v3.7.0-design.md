# v3.7.0 — UX Polish + Layout Refactor (Design Spec)

**Date:** 2026-05-09
**Status:** Approved (kickoff)
**Position:** First post-IPv6-roadmap minor release. The four-release IPv6
surface (v3.3.0–v3.6.0) is feature-complete; v3.7.0 pivots to UX polish.

## Milestone context

- v3.6.4 just shipped (cleanup patch). Production healthy on v3.6.4.
- The IPv6 tab now exposes 19 tool triggers (after 13 new tools across
  v3.3.0–v3.6.0). Mobile users see ~10 rows of buttons before reaching
  the calculator inputs.
- `templates/layout.php` has grown to ~3200 lines. Reviewers in v3.5.0
  T2/T3 flagged it as "growing past comfortable size."
- `#420` from the production manual review documents 4 concrete UX
  issues at narrow viewports.
- Several minor CR nits from v3.5.x/v3.6.x have accumulated.

## Goal

Address #420 mobile UX gaps, refactor `templates/layout.php` into
per-tool partials to enable easier per-drawer mobile/desktop styling,
group the 19 IPv6 tool triggers into navigable categories, replace
`:focus` with `:focus-visible`, and absorb the deferred CR-nit cleanups
from v3.6.x.

## Non-goals

- No new tools (IPv6 surface is feature-complete per the original roadmap).
- No new top-level tabs.
- No new design tokens. Reuse existing `--color-*` only.
- No API surface changes (no breaking endpoints, no new operations).
- No `ul_bit_flipped` rename (still v4.0.0).
- No performance/Lighthouse work (separate future minor if signal warrants).

## Audience

Same as v3.3.0–v3.6.x: anyone who needs an IPv4/IPv6 calculator. Mobile
users disproportionately benefit from this release.

## Architecture

Sequential PR fan-out off `release/v3.7.0`. T2 (refactor) lands first
because T3/T4 build on it. T5 (`:focus-visible`) and T6 (CR-nit cleanup)
are independent and can land in parallel between T2 and T7. T7 (a11y
polish) builds on T2/T3 markup. T8 is the release cut.

The drawer-partial refactor splits `templates/layout.php` into:
- `templates/layout.php` — page chrome, header, tab strip, footer (slim)
- `templates/_panels/ipv4.php`, `_panels/ipv6.php`, `_panels/vlsm.php`,
  `_panels/vlsm6.php` — per-tab panel scaffolding
- `templates/_tools/<name>.php` — one file per drawer (≥30 files)

Per the plan's "design for isolation" principle, each tool partial
becomes independently understandable; future tool additions only touch
their own file plus a one-line include.

## Carry-forward debt items (absorbed inline)

### #1 `cidrs_overlap()` `explode('/', $cidr, 2)` limit param (T6)

**Where:** `Subnet-Calculator/includes/functions-ipv4.php` (and `-ipv6.php` for `cidrs_overlap6()`).

**Issue:** `explode('/', $cidr)` without limit returns variable-length
arrays for malformed input. Bound to `2` for safety even though the
v3.6.4 validation already rejects missing slash.

### #2 `session_create()` docblock says "8-character hex ID" (T6)

**Where:** `Subnet-Calculator/includes/functions-session.php`.

**Issue:** v3.6.4 widened to 16-char; docblock not updated.

### #3 OpenAPI may reference 8-char session IDs in examples (T6)

**Where:** `Subnet-Calculator/api/openapi.yaml`.

**Issue:** v3.6.4 widening; examples might still show 8-char IDs. Audit
and update.

### #4 `index.php` and `_tree_editor.php` lack `declare(strict_types=1)` (T6)

**Where:** `Subnet-Calculator/index.php`, `Subnet-Calculator/templates/_tree_editor.php`.

**Issue:** These files predate the strict-types convention applied to
v3.5.x/v3.6.x modules. Add the declaration; verify nothing breaks.

## UX items (#420)

### #5 Mobile h1 truncation (T4)

**Where:** `Subnet-Calculator/assets/app.css` header rules.

**Issue:** Title clamps to `Subnet Cal...` at 375px viewport.

**Fix candidates:**
- Allow h1 to wrap at <480px.
- Use shorter mobile-only label via `:before/:after` content swap.
- Drop header action buttons below title at <480px.

Pick during implementation.

### #6 Mobile tab strip overflow (T4)

**Where:** `Subnet-Calculator/assets/app.css` tab strip rules.

**Issue:** Four tabs (IPv4, IPv6, VLSM, VLSM IPv6) overflow horizontally
at 375px; "VLSM IPv6" nearly clips.

**Fix:** 2×2 grid below 480px.

### #7 IPv6 wall-of-buttons (T3)

**Where:** `Subnet-Calculator/templates/_panels/ipv6.php` (after T2 split).

**Issue:** 19 tool triggers stack as 10+ rows on mobile, hiding the
calculator below.

**Fix:** Group into 5 collapsible categories (`<details>` with sensible
default-open state):
- **Foundational** (4 tools): split6, ula, range6, supernet6.
- **Address utilities** (4 tools): zone-id, derive, slaac, rdns6.
- **Transition** (6 tools): mapped6/nat64, embedded-v4, 6to4, teredo,
  isatap, 6rd.
- **Prefix planning** (3 tools): prefix-plan, nibble, rfc3531.
- **Multicast** (4 tools): multicast, ssm, embedded-rp, pmtu.

Keep all groups expanded by default on first visit (no surprise
hiding); persist user-collapse state via `localStorage`.

### #8 Sticky focus ring (T5)

**Where:** `Subnet-Calculator/assets/app.css` `:focus` selectors.

**Issue:** Mouse clicks leave the teal `--color-accent` outline persistent
on tool triggers.

**Fix:** Replace `:focus` with `:focus-visible` across the codebase.
Verify keyboard focus retains the ring; mouse clicks don't.

## Layout refactor (T2)

`templates/layout.php` (currently ~3200 lines) splits into:

1. `templates/layout.php` — page chrome only:
   - `<head>`, header, tab strip, footer, theme-init script,
     bg-override style block.
   - Total: ~150 lines.
2. `templates/_panels/ipv4.php` — IPv4 tab panel scaffolding (form,
   error, result panel) + `<?php require '_tools/<name>.php'; ?>` for
   each IPv4 tool.
3. `templates/_panels/ipv6.php` — same shape for IPv6 tab.
4. `templates/_panels/vlsm.php` — VLSM tab.
5. `templates/_panels/vlsm6.php` — VLSM IPv6 tab.
6. `templates/_tools/<name>.php` — one file per drawer. ~30 files.

Each `_tools/<name>.php` partial:
- Reads its `data-tool="<name>"` from a `$_tool_slug` local.
- Renders the trigger button + drawer panel.
- Receives result data from the parent panel via existing globals
  (`$mapped6`, `$ssm6`, `$multicast6`, etc.). No new data flow.

**No behaviour change.** Playwright suite is the safety net; every
existing test should pass without modification.

**Plan invariant:** the markup output of `templates/layout.php` (post-
refactor) must be byte-for-byte identical to v3.6.4 output, modulo
whitespace from the includes.

## Sequencing

| PR | Task | Title | Depends on |
|---|---|---|---|
| **1** | T1 | Branch + living-doc + memory bootstrap | — |
| **2** | T2 | Extract `templates/_tools/*.php` partials | T1 |
| **3** | T3 | Group IPv6 tool triggers into 5 collapsible categories | T2 |
| **4** | T4 | Mobile layout fixes (h1, tab strip, drawer width) | T2 |
| **5** | T5 | `:focus` → `:focus-visible` sweep | (parallel-safe) |
| **6** | T6 | CR-nit cleanup batch (cidrs_overlap explode limit, session docblock, OpenAPI session-ID examples, declare(strict_types=1) on index.php + _tree_editor.php) | (parallel-safe) |
| **7** | T7 | A11y polish (tab-order strictness, prefers-reduced-motion explicit, focus-return per drawer) | T2, T3 |
| **8** | T8 | Release cut → tag → publish → deploy (with `sleep 3` after lsws restart per v3.6.3 lesson) | T2-T7 |

T5 and T6 land between T2 and T7 in any order.

### Sequencing rationale

- **T2 first** — refactor unlocks T3 (per-panel grouping) and T4 (per-
  drawer mobile rules). Doing T3/T4 inline in the monolith is more
  fragile.
- **T3 → T4** — grouping changes the panel structure; mobile rules
  apply on top of grouped markup.
- **T5/T6 parallel-safe** — independent of refactor.
- **T7 after T2/T3** — a11y assertions test the new markup structure.
- **T8 last** — release-cut.

## Risks

1. **T2 refactor blast radius.** Touches every drawer; Playwright is
   the only meaningful safety net. **Mitigation:** Plan invariant
   above (output must be byte-identical). Run full suite before AND
   after each panel split.
2. **T3 grouping UX risk.** Collapsing groups by default could hide
   tools users currently see. **Mitigation:** Default to all groups
   expanded; persist user-collapse state in localStorage. First-time
   visitors see the full set.
3. **T5 `:focus-visible` browser support.** Baseline since 2022; safe
   per Caniuse. **Mitigation:** Keep `:focus` rules as fallback for
   ancient browsers if needed; verify with manual mobile-Safari smoke.
4. **Eight PRs vs. seven in v3.6.0.** Modest scope creep. **Mitigation:**
   T5 and T6 are small (~30-min each); the workload is dominated by T2.

## Out of scope

- New tools.
- New top-level tabs.
- New design tokens.
- API-breaking changes.
- `ul_bit_flipped` rename → v4.0.0.

- Performance/Lighthouse work → separate future minor.
